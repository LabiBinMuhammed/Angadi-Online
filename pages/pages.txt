# 🔐 AUTHENTICATION

## Splash Page 

**Purpose:** Entry gate + session validation

**Features:**

* App logo + loading indicator
* Auto-check authentication token
* Fetch minimal user data (id, role)
* Redirect logic:

  * logged in → Home
  * not logged → Login

**Edge Cases:**

* Token expired → force logout
* Network failure → retry or fallback

---

## Login Page

**Purpose:** Authenticate user

**Features:**

* Input: phone
* Input: password OR OTP toggle
* “Send OTP” flow
* Validation messages
* Login button
* Link to Signup

**Actions:**

* API call → auth
* Store token securely

**Edge Cases:**

* wrong OTP/password

---

## Signup Page

**Purpose:** Register new user

**Features:**

* Name
* location (dropdown selecting)
* Phone (primary identity)
* Password / OTP
* Role (default customer)

**Actions:**

* Create user
* Auto-login after success

---
